# Third-party notices

## Shipped in the game build

The production build (`dist/`, and the release ZIP) contains this project's own code
and content, three font families, and the small module-preload helper that the Vite
bundler adds to its output (Vite code, MIT-licensed).

### Fonts

The fonts are bundled as local `.woff2` files (Latin subsets), so the game needs no font
service at run time. They come from the Fontsource packages below. The package code is
MIT-licensed, and the font files are under the **SIL Open Font License 1.1**. The licence
texts ship with the build in `licenses/`.

| Font | Designer | Licence | Package | Version |
|---|---|---|---|---|
| Alegreya (variable) | Juan Pablo del Peral, Huerta Tipográfica | OFL-1.1 | @fontsource-variable/alegreya | 5.3.0 |
| Alegreya SC | Juan Pablo del Peral, Huerta Tipográfica | OFL-1.1 | @fontsource/alegreya-sc | 5.3.0 |
| Source Sans 3 (variable) | Paul D. Hunt, Adobe | OFL-1.1 | @fontsource-variable/source-sans-3 | 5.3.0 |

### Everything else is original

- **Images:** none are bundled. The map, terrain art, heraldry, markers, icons and favicon
  are drawn with Canvas or inline SVG by this project.
- **Audio:** none is bundled. All sounds are synthesised with the Web Audio API at run time.
- **Content:** the map geometry is generated by `tools/genmap.ts` (the Reach) and
  `tools/genworld.ts` (Aldmere) from original, authored geography. All names, realms,
  heraldry, events and text are original to this project.
