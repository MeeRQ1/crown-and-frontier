# Third-party notices

## Shipped in the game build

The production build (`dist/`, and the release ZIP) contains only this project's own
code and content, plus the small module-preload helper that the Vite bundler adds to
its output. That helper is Vite code, MIT-licensed.

- **Fonts:** none are bundled. The interface uses the system font stack (system-ui, Georgia).
- **Images:** none are bundled. The map, markers and favicon are drawn with Canvas or inline SVG
  generated by this project.
- **Audio:** none is bundled. All sounds are synthesised with the Web Audio API at runtime.
- **Content:** the map geometry is generated by `tools/genmap.ts` from original province
  positions. All names, realms, events and text are original to this project.
